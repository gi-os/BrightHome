    Setting up the tunnel
    
    
      
  1. Run the cloudflared add-on and point a tunnel hostname at http://homeassistant:8123.
    2. 
      
  2. Tell Home Assistant to trust it, or every request is dropped:
        
    http:
  use_x_forwarded_for: true
  trusted_proxies:
    - 172.30.33.0/24
    
      
    3. 
      
  3. Optional but worth it: put an Access application in front of the hostname so the login page is not on the open internet, then create a service token for BrightHome. Access cannot run an interactive login against an app, which is why the service token exists.
    4. 
      
  4. Add a policy on that application with the action Service Auth and the service token as its include rule.
